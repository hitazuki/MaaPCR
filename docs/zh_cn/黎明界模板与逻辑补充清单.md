# 黎明界模板与逻辑补充清单

本文配合 `assets/resource/pipeline/limingjie_task.json` 使用，记录基础框架后续需要补充的模板、识别范围和策略逻辑。

## 当前框架状态

已新增基础入口：

- 任务入口：`黎明界(基础框架)`
- Pipeline：`assets/resource/pipeline/limingjie_task.json`
- 当前识别方式：以 OCR 和固定坐标为主
- 当前默认策略：
  - 初始角色：默认点击前三个候选角色
  - 地图节点：优先尝试 OCR 识别 `BOSS`、`NORMAL`、`EVENT`、`SHOP`
  - 奖励：默认选择左侧第一项
  - 商店：默认直接离开
  - 失败：默认停止任务

该框架只用于串联流程，稳定运行前必须补充地图节点、入口、奖励和异常模板。

## 需要补充的逻辑

### 入口逻辑

- 从主页进入黎明界的路径还没有落地。
- 需要确认入口是否固定在活动页、主界面横幅或其他菜单。
- 需要补充入口模板和点击坐标。

### 地图选路逻辑

当前只按 OCR 识别节点文字，缺少路线优先级和可达性判断。

待补：

- 可达节点识别。
- 已清除节点过滤。
- 多分支节点排序。
- 高难节点是否避开。
- `NORMAL`、`EVENT`、`SHOP`、`BOSS` 的优先级配置。
- 区域结束后的传送/动画等待。

### 角色选择逻辑

当前默认选前三个候选角色。

待补：

- 初始角色优先级表。
- 角色奖励三选一优先级。
- 角色头像模板或 OCR 名称识别。
- 已选择角色状态识别。
- 缺少高优先角色时的替补规则。

### 道具/符号/遗物逻辑

当前默认选左侧第一项。

待补：

- 道具优先级表。
- 属性符号优先级。
- 同名不同品质或不同图标的识别规则。
- 连续奖励次数识别。
- 已持有遗物数量或效果影响下的选择策略。

### 商店逻辑

当前默认直接离开，另有“停在商店等待人工”选项。

待补：

- 商品格识别。
- 商品价格识别。
- 当前货币识别。
- 购买优先级。
- 货币不足处理。
- 购买确认弹窗循环。
- 买完后离开商店。

### 战斗逻辑

当前把战斗视为黑盒，只等待胜败。

待补：

- Auto 状态识别和开启。
- 倍速状态识别和开启。
- 战斗超时处理。
- 失败后返回地图、换队或重试策略。
- 高难战斗是否启用手动/暂停策略。

### 编队逻辑

当前只点击 `バトル開始`。

待补：

- 队伍槽选择。
- 自动换人。
- 战力不足/角色倒下后的替补规则。
- EX 装备自动配置。
- 编队页误入后的返回规则。

### 异常恢复逻辑

待补：

- 连接超时弹窗。
- 回标题页后的恢复路径。
- 下载资源弹窗。
- 通用关闭/确认弹窗优先级。
- Loading 和 Connecting 的等待策略。
- 连续失败次数上限。

## 建议迭代顺序

1. 补齐第一优先级模板。
2. 将 `limingjie_task.json` 中 OCR 节点逐步替换为 TemplateMatch。
3. 先验证单一路线能否从入口跑到结算。
4. 增加地图选路优先级。
5. 增加角色和道具优先级。
6. 增加商店购买策略。
7. 最后处理高难失败重试和 EX 装备。
